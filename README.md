# Yomira

Yomira is a fork of [ScummVM](https://www.scummvm.org/) that focuses on engines for visual novels, eroge, and similar games. Like ScummVM, it reimplements each game's engine and runs it from your own copy of the original game data.

It was forked from ScummVM to avoid potential issues with adult content in the upstream project.

The command-line help describes it as "Yomira - Visual Novel Interpreter". It is an independent fork, not an official ScummVM release, and is not affiliated with or endorsed by the ScummVM project.

**Unless you can confirm a bug also occurs in upstream ScummVM, report it to this repository's issue tracker.**

## Status

The Yomira-specific engines are young. Most are experimental or cover only a title menu, and no game is verified as completable. Games and caveats are listed in [COMPATIBILITY.md](COMPATIBILITY.md).

| Engine | Games | State |
| --- | --- | --- |
| [XEX](engines/xex/README.md) | 10 Japanese Windows titles from Complet (XEX and C4 engines) | Experimental: gameplay, audio, save/load, message history, and CG galleries are implemented; not every route is verified. |
| [Delta](engines/delta/README.md) | 2 Japanese Windows titles from Route Two Ltd. | Title menus and limited opening scenes in One Lover; story execution incomplete. |
| [Illusion](engines/illusion/README.md) | Sexy Beach 2 (Japanese, Windows) | Title menu only. |
| [System-98](engines/system98/README.md) | Mugen Yasoukyoku (Japanese, PC-98) | Partial: main menu, Options, MIDI audio; no full gameplay or save/load. |

Several of the detected games are adult titles. Detection entries for Delta and Illusion are flagged unstable, and System-98 shows a limited-support warning on launch.

### Inherited ScummVM support

Yomira does not include the engines and game support inherited from upstream ScummVM. For those titles, please use ScummVM directly.

## Game data

Yomira does not ship game data. Copy the files from your own original media into a directory, one directory per game, keeping the original subdirectory layout. Detection matches specific files by size and MD5, so unrecognized releases, translations, or partial extractions will not be detected.

Several Yomira engines also need a Japanese font (for example `NotoSansCJK-Regular.ttc`) and ScummVM's `encoding.dat`. Per-engine file requirements are in each engine's README.

## LLM Disclosure

Yomira development makes extensive use of large language models (LLMs) for code generation, documentation, and other development tasks. Users should be aware that some parts of the codebase may have been influenced or generated by LLMs.

Most of the reverse engineering work and engine implementation has been carried out by LLM-assisted development, with human oversight and guidance to ensure accuracy and functionality.

## Getting started

Build from source, then add your game:

```sh
./configure
make -j2
```

`./configure --help` lists options for your platform, and [.github/workflows/ci.yml](.github/workflows/ci.yml) shows the configurations built in CI. XEX, Delta, System-98, and Illusion are enabled by default but declare dependencies in their `configure.engine` files (`16bit`, `highres`, `freetype2`, `midi`, `tinygl`); see [COMPATIBILITY.md](COMPATIBILITY.md#engine-notes). To enable an engine explicitly, use `--enable-engine=<name>`, for example `--enable-engine=xex`. The build requires locally installed development libraries.

Then:

1. Start Yomira, choose **Add game**, select the directory containing the game data (not the data files themselves), and press **Choose**.
2. Review the Game Options, or leave the defaults.
3. Select the game in the list and press **Start**.

To add several games at once, use the small arrow on **Add game** and choose **Mass Add**.

Run the unit tests with `make test`; see [test/README](test/README) for details.

## Reporting a bug

For Yomira-specific problems, including the engines above, use this repository's issue tracker. For problems that also occur in upstream ScummVM, report them to the [ScummVM issue tracker](https://bugs.scummvm.org/) after checking that they reproduce there.

Include:

- Yomira version
- Game, language, and release (for example, the detection entry name)
- Platform and compiler (for example, Linux or Windows)
- Steps to reproduce, with log files, screenshots, or a saved game where possible
- If the bug is a regression, the last good and first bad version

Please file each issue separately.
